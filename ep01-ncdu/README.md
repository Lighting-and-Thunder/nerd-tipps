# Nerd Tipps #01 Mehr Speicherplatz

## 1. ncdu installieren

```
brew install ncdu
```

## 2. Benutzung

Navigiere mit Pfeiltasten ``(← ↑ ↓ →)``

oder vim keybindings ``(h, j, k, l)``

drücke `d` um etwas zu löschen.

Achtung: alles was du mit ncdu löscht, landet nicht im Papierkorb. Es ist für immer gelöscht!
